# Nova Practise test

Offline-first clinic management application for Sri Lanka built with Electron, Node.js, and SQLite.

## Features
- Offline-first clinic operations with local SQLite storage
- Cloud synchronization and QR-based mobile interaction
- Prescription, patient records, and billing management

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
npm install
```

### Running the Application
```bash
npm start
```
