Step 1: Database & System Configuration

Synchronize and verify local clinical database schema, audit log tables, relational roles, and security policies.

Database Storage: clinic.db (SQLite WAL Mode)
Relational Schema: users, roles, modules, user_module_permissions, consultations, prescriptions
Security Engine: SHA-256 One-Way Password Hashing (Zero Plaintext Storage)
Default Roles: Doctor, Receptionist, Pharmacist
Database Readiness: ✓ System Synchronized

Create accounts with dynamic roles loaded from the database. Passwords will be securely hashed with SHA-256.
